Description

GEDTM30 is presented as a 1-arc-second (~30m) global Digital Terrain Model (DTM) generated using machine-learning-based data fusion. It was trained using a global-to-local Random Forest model with ICESat-2 and GEDI data, incorporating almost 30 billion high-quality points. To see the documentation, please visit our GEDTM30 Codeberg(https://codeberg.org/openlandmap/GEDTM30).

This dataset covers the entire world and can be used for applications such as topography, hydrology, and geomorphometry analysis.

Dataset Contents

This dataset includes:

GEDTM30
Represents the predicted terrain height.

Uncertainty of GEDTM30 prediction
Provides an uncertainty map of the terrain prediction, derived from the standard deviation of individual tree predictions in the Random Forest model.

Global-to-local pixel selection mask A mask that indicates which pixel comes from the global model or local model.

Due to Zenodo's storage limitations, the zenodo files are in 240m resolution, and the original GEDTM30 dataset and its standard deviation map are provided via external links:
